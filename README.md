# ScootyKik 🛵
**Ride India. Feel India.**

Play now: [scootykik.vercel.app](https://scootykik.vercel.app)

A free Indian street racing game built as a Progressive Web App (PWA). Experience premium third-person riding physics, custom synthesized audio, and iconic Indian street sceneries.

## 🌟 Features
- **Indian Street Theme**: Ride through Tamil Nadu Village, Bangalore City, AP Highway, AP Village, Mumbai Sea Link, and Delhi Highway.
- **Progressive Web App (PWA)**: Install directly on Android or iOS and play completely offline.
- **High-Fidelity Audio Synthesis**: Procedurally synthesized double-beep horns, adapting engine rumble, and retro arpeggio coin chimes using the Web Audio API.
- **Optimized Performance**: Level-of-Detail (LOD) check rendering system for solid 60 FPS on mobile.

## 🚀 How to Run Locally
Start a local server to play:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
